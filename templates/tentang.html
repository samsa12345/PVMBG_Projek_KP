Library & Teknologi

Perangkat lunak, framework, dan pustaka komputasi yang digunakan dalam pipeline eksperimen dan aplikasi backend:

TensorFlow / Keras
Untuk arsitektur ResNet50, MobileNetV2, training, inference, dan manajemen model deep learning.
scikit-learn
Untuk GroupShuffleSplit, K-Means clustering, PCA, dan perhitungan metrik evaluasi.
OpenCV
Untuk pra-pemrosesan citra CCTV, CLAHE contrast enhancement, dan operasi matriks piksel.
Pillow (PIL)
Untuk validasi integritas file gambar, decoding format citra, dan manipulasi orientasi.
NumPy
Untuk manipulasi array multidimensi, matrik fitur 1.280D, dan kalkulasi jarak Euclidean.
Pandas
Untuk pengelolaan data metadata citra, penanganan file CSV, dan agregasi laporan eksperimen.
Matplotlib / Seaborn
Untuk visualisasi grafik kurva training loss/accuracy, confusion matrix, dan distribusi anomaly score.
joblib
Untuk serialisasi dan penyiapan model K-Means cluster centroid yang siap digunakan pada server.
⚠
Catatan Metodologi & Disclaimer Resmi:

Output machine learning merupakan hasil pemrosesan citra berdasarkan dataset dan konfigurasi eksperimen yang digunakan. Hasil klasifikasi dan anomaly detection tidak menggantikan pengamatan visual, validasi data, maupun penilaian resmi dari pihak berwenang.

Tangkuban Perahu: Anomaly detection bersifat unsupervised. Kandidat anomali menunjukkan penyimpangan visual terhadap pola feature space yang dipelajari dan tidak secara otomatis berarti terjadi erupsi.
